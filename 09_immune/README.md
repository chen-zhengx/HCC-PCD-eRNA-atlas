# 09_immune: immune cell-type signatures and immune-rank subtypes

This module computes single-sample GSEA (ssGSEA) enrichment scores of 28 immune cell-type signatures for the 70
GSE144269 tumors, compares them between the PCD-related molecular subtypes, derives immune-rank subtypes from the
within-sample ranking of the 28 signatures, and cross-tabulates the two classifications (Figure 6, Table S10).
