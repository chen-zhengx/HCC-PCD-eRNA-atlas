# 05_prognostic_model: PCD-related eRNA prognostic models (GSE144269)

This module builds the anoikis-, apoptosis- and ferroptosis-related eRNA prognostic models in the GSE144269 cohort (70
HCC tumors, 23 deaths), draws the LASSO, Kaplan–Meier and time-dependent ROC panels, performs the internal validation,
and reproduces the model coefficients and performance (Tables S7 and S8) and the Venn diagram of the model eRNAs
(Figure S3).
