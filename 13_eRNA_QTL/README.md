# 13_eRNA_QTL: eRNA-QTL analysis

This module reproduces the exploratory eRNA-QTL analysis in GSE144269: the association of SNP genotypes called from
RNA-seq with the expression of the 12 risk eRNAs in the 70 tumors with MatrixEQTL, using tumor-derived genotypes in
the primary analysis and genotypes from the paired adjacent non-tumor tissue as a sensitivity analysis, and the
genotype box plots of the cis-eRNA-QTLs (Figure 9).
