# 10_immunotherapy: immunotherapy response-related biomarkers (tigeR)

This module scores 23 published immunotherapy response-related signatures with the tigeR R package in the 70 GSE144269
tumors and compares them between the two molecular subtypes of each PCD classification (Figures 7, S6 and S7). It also
contains the immunotherapy-related gene list given in Table S5.
