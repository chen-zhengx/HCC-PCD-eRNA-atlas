# 12_network: multilayer co-expression association networks

This module reproduces the multilayer co-expression association networks of the anoikis-, apoptosis- and
ferroptosis-related risk eRNAs in the 70 GSE144269 tumors, which link each risk eRNA by Spearman correlation to
candidate target genes within ±1 Mb, PCD-related genes, immune cell-type signatures, candidate drugs and
immunotherapy-related genes, together with the network summaries, Figures 8, S8 and S9, and Supplementary Table 12.
