# 02_differential_expression: shared differentially expressed eRNAs and genes (Figure 2)

This module reproduces the differential expression analysis of eRNAs and protein-coding genes between tumor and paired
non-tumor tissue in each of the six datasets, which combines expression-state classification, a paired limma analysis
and McNemar's test, and the intersection across datasets that yields the 559 shared differentially expressed eRNAs and
649 shared differentially expressed genes shown in Figure 2.
