# 04_erna_gene_correlation: PCD-related eRNAs (Table 1, Table S6)

This module reproduces the Spearman correlation analysis between the shared differentially expressed eRNAs and the
differentially expressed anoikis-, apoptosis- and ferroptosis-related genes in each dataset, the selection of shared
significant eRNA–gene pairs that defines the PCD-related eRNAs (Table 1), and the sensitivity analysis of confounding
by tissue status reported in Supplementary Table 6 and the accompanying Supplementary Data.
